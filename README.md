# World Happiness Report Analysis (2015–2019)

An end-to-end data analytics project that explores global happiness trends using **Python**, **SQL**, and **Power BI**. This project transforms raw data into actionable insights through data cleaning, exploratory data analysis (EDA), SQL-based analysis, and an interactive dashboard.

---

##  Project Overview

The **World Happiness Report** evaluates countries based on factors that influence overall happiness, including GDP, health, social support, freedom, generosity, and perceptions of corruption.

The objective of this project was to perform a complete analytics workflow—from raw CSV files to an interactive business dashboard—while emphasizing clear, user-friendly data visualization.

# Dashboard Overview

The Power BI dashboard is divided into three pages to provide a structured analytical journey.

---

## Page 1 – Executive Overview

This page provides a high-level summary of the dataset.

- Average Happiness Score
- Average GDP

---

This page explores relationships between Happiness Score and major contributing factors.

### Visuals Included

- Happiness Score vs GDP
- Happiness Score vs Health

Each scatter plot includes a trend line to visualize the relationship between variables.

## Page 3 – Country Insights

# Key Insights

Some of the major findings from the analysis include:

- Countries with higher GDP generally report higher happiness scores.
- Health (Life Expectancy) demonstrates a strong positive relationship with happiness.
- Social Support is another major contributor to happiness.
- Global happiness remained relatively stable between 2015 and 2019.
- Nordic countries consistently rank among the happiest countries in the world.
